# ☕ Villa Doce Café

Aplicação web responsiva desenvolvida em React para a cafeteria **Villa Doce Café**, oferecendo uma experiência moderna e intuitiva para visualização do cardápio, navegação por categorias e gerenciamento de carrinho de compras.

---

## 📖 Sobre o Projeto

O Villa Doce Café foi desenvolvido como projeto acadêmico com o objetivo de aplicar conceitos de desenvolvimento Front-End utilizando React.

A aplicação permite que os usuários naveguem pelo cardápio da cafeteria, filtrem produtos por categoria e adicionem itens ao carrinho de compras através de uma interface responsiva e de fácil utilização.

---

## ✨ Funcionalidades

* 📋 Exibição do cardápio de produtos
* 🔍 Filtragem de produtos por categoria
* 🛒 Carrinho de compras com armazenamento local
* 📱 Layout responsivo para dispositivos móveis e desktop
* ⚡ Navegação dinâmica utilizando React Router

## ⚙️ Como Executar o Projeto

### Pré-requisitos

* Node.js instalado
* NPM instalado

### Instalação

Clone o repositório:

```bash
git clone https://github.com/seu-usuario/villa-doce-cafe.git
```

Acesse a pasta do projeto:

```bash
cd villa-doce-cafe
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Após iniciar, acesse:

```text
http://localhost:5173
```
